Commands

Use the $ prefix or slash commands

$ban Ban a member
$kick Kick a member
$mute Timed mute (30s-14d)
$unmute Remove timeout
$warn Warn a member
$warnings View warnings
$purge Bulk delete messages
$giveaway Start a giveaway
$giveawayend End giveaway early
$giveawayreroll Reroll winner
$invites Check invite stats
$inviteboard Invite leaderboard
$count Check counting game
$role Add/remove roles
$userinfo Member info card
$serverinfo Server info
$avatar Get user avatar
$ping Check bot latency
$poll Create a reaction poll
$8ball Magic 8-ball
